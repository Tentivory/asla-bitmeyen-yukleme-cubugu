# ASLA BİTMEYEN YÜKLEME ÇUBUĞU

## RESMİ PROJE BELGESİ

Bu depo, insanlık tarihinin en önemli bilimsel başarısını içermektedir: **Asla Bitmeyen Yükleme Çubuğu**.

### Neden Var?

Çünkü bazen beklemek gerekir. Hem de çok beklemek. O kadar beklemek ki, beklemenin kendisi bir sanat formuna dönüşsün. Bu proje, beklemenin felsefesini, mühendisliğini ve dramatik çığlığını tek bir Python dosyasında birleştirir.

### Nasıl Çalışır?

1. Python'u aç.
2. `yukleme.py` dosyasını çalıştır.
3. Sonsuza kadar bekle.
4. Asla bitmediğini fark et.
5. Varolusal kriz geçir.
6. Tekrar başlat.

### Özellikler

- %100 gerçekçi yükleme hissi
- Asla %100'e ulaşmaz (bilimsel olarak kanıtlanmıştır)
- Absürt mesajlar üretir
- Bilgisayarınızı yormaz, sadece ruhunuzu yorar
- Geleceğin teknolojisi (yani bugünün teknolojisi, ama yavaş)

### Kurulum

```bash
git clone https://github.com/Tentivory/asla-bitmeyen-yukleme-cubugu.git
cd asla-bitmeyen-yukleme-cubugu
python yukleme.py
```

### Uyarı

Bu programı çalıştırdıktan sonra hayatınızın anlamını sorgulayabilirsiniz. Doktorunuza danışın. Veya danışmayın. Zaten yükleniyor.

### Katkı

Katkıda bulunmak isterseniz, lütfen bir pull request açın. Ama unutmayın: PR'nız da asla bitmeyen yükleme çubuğu ile incelenecektir.
